נדרש הגדרה חד-פעמית

כדי להציג נתונים אמיתיים מ-GA4, צריך להוסיף שני ערכים לקוד הדף. זה לוקח כ-10 דקות.

שלב 1 — מצא את ה-Property ID שלך ב-GA4

  1. GA4 → Admin (גלגל השיניים) → Property Settings
  2. העתק את ה-Property ID (מספר כמו 123456789)
  3. פתח את analytics.html והחלף YOUR_PROPERTY_ID

שלב 2 — צור OAuth Client ID ב-Google Cloud

  1. כנס ל-console.cloud.google.com
  2. APIs & Services → Enable APIs → אפשר את Google Analytics Data API
  3. Credentials → Create Credentials → OAuth 2.0 Client ID → Web Application
  4. ב-Authorized JavaScript Origins הוסף את הדומיין שלך
  5. העתק את ה-Client ID והחלף YOUR_CLIENT_ID ב-analytics.html

הדף הזה הוא noindex — לא יופיע בגוגל.
