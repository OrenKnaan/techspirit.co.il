נדרש הגדרה חד-פעמית

כדי להציג נתונים אמיתיים מ-GA4, צריך להוסיף שני ערכים לקוד הדף.

שלב 1 — Property ID

  1. GA4 → Admin → Property Settings → העתק את ה-Property ID
  2. פתח analytics/index.html והחלף YOUR_PROPERTY_ID

שלב 2 — OAuth Client ID

  1. Google Cloud Console → Credentials → OAuth 2.0 Client ID
  2. הוסף את הדומיין ב-Authorized JavaScript Origins
  3. החלף YOUR_CLIENT_ID בקוד

הדף הזה הוא noindex — לא יופיע בגוגל.
