How it works

You click once. It does the rest.

Downscript is two small tools working together: an extension that browses like you do, and a quiet companion on your Mac that does the heavy lifting.

  1. 01

    Open a profile, press Start

    Visit any TikTok profile and click the Downscript icon (or press ⌘⇧E). That's the last thing you have to do.

  2. 02

    The extension gathers every video

    It scrolls the whole grid for you, collecting each video as it appears — including ones TikTok unloads from the page as you go.

  3. 03

    Your Mac writes the transcripts

    A local companion downloads each video, converts the audio, and transcribes it with Whisper — then saves a clean Markdown file to your Downloads folder.

Why Downscript

Built for whole profiles, not single videos.

Copy-pasting one caption at a time doesn't scale. Downscript treats a creator's entire body of work as one job.

Every video, one run

Point it at a profile and it captures the full grid — hundreds of videos if that's what's there — without you babysitting the scroll.

Private by design

Downloading, audio conversion, and transcription all happen on your Mac. Nothing is uploaded, logged, or shared — there's no server to send it to.

Picks up where it left off

Cancel any time, close the popup, even restart Chrome — the next run skips finished transcripts and resumes the rest.

Gentle with social networks

Downloads are paced with pauses and patient retries, so long runs finish quietly without causing issues on the platform.

Clean Markdown files

Each transcript is a tidy .md file with the title, link, and caption — ready for Obsidian, Notion, an AI workflow, or plain reading.

Live progress, always

A badge on the toolbar icon, a live log in the popup, and a notification when the batch is done. You always know where a run stands.

Setup

A one-time, five-minute setup.

Downscript is a local tool, so it's installed by hand rather than from a store. In exchange, nothing about it is hidden — you can read every line it runs.

You'll need on your Mac

  • Google Chrome, signed in to TikTok
  • yt-dlp — fetches the videos
  • ffmpeg — converts audio
  • whisper-cli + a Whisper model — transcription
  • Python 3 (ships with macOS)

The extension's settings page has a "Check setup" button that verifies all of these for you, with a green light per row.

  1. Load the extension

    Open chrome://extensions, switch on Developer mode, choose Load unpacked, and select the extension folder.

  2. Register the companion

    One command connects Chrome to the local transcription pipeline:

    cd downscript/companion
./install.sh

  3. Check, then run

    Open the extension's settings, press Check setup, and wait for four green rows. Then visit any TikTok profile and press Start Extraction.

Questions

Asked and answered.

No. The only network traffic is between your Mac and the social network itself, to fetch the videos. Transcription runs on your own processor, and the transcripts are written straight to your Downloads folder. There is no central server.

Chrome extensions cannot run programs or write files on your computer directly. This is a deliberate safety rule. The extension does the browsing, and a small local companion runs the downloading and transcribing. Chrome connects the two through its official native messaging channel.

The system is built to support TikTok, Instagram, Facebook, and YouTube profiles. The extension uses a platform adapter design to ensure consistent extraction across all supported sites.

downscript extracts transcripts through a local multi-step pipeline. The browser extension collects video permalinks from the target profile. It forwards these links to the native companion. The companion uses yt-dlp to download the high-quality audio stream to a local temporary folder. Next, ffmpeg transcodes this audio into a 16 kHz mono PCM WAV format. The locally installed whisper-cli binary processes this WAV file on your device CPU. It generates plain text transcripts. Finally, the companion formats this text into a clean Markdown file with metadata frontmatter and a table of contents.
